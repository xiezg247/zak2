# 看板顶部工具条设计

> 日期：2026-08-19

## 背景

看板页（`frontend/src/views/BoardView.vue`）顶部当前堆叠两段：「仓位与风控」整行卡 + 「策略看盘」工具条（标题、meta、模式 tabs、操作按钮），纵向占用大、信息分散。用户希望布局更紧凑。

## 目标

将顶部重构为**一条工具条**，三段式布局，压缩纵向占用。

## 设计

### 布局

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 策略[启发式确认▾] │ 总资金[   ] 止损%[   ] 浮亏警戒[   ] [保存风控] │ [同参回测][入队回测][刷新看板] │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 左段：策略下拉选择（`SIGNAL_MODES` 数组渲染，后续新增策略只加一项；沿用 `signalMode` ref、本地记忆、切换刷新逻辑）
- 中段：风控三输入 + 保存按钮（原风控卡压缩为一行紧凑输入）
- 右段：同参回测 / 入队回测 / 刷新看板（沿用现有按钮与 handler）
- 窄屏（≤900px）三段折行

### 移除内容

- 「策略看盘」大标题（`.board-head` 的 `h2`）
- meta 行：`config_key · signal_mode · source · as_of`
- 「实际仓位」展示（用户选择不需要）
- `riskSummary` computed、`formatPctRatio` 函数（不再引用，避免 unused）

### 保留内容

- 风控保存逻辑、错误/成功提示（移到工具条下方一行小字，`prefsReady` / `riskError` / `riskMsg` 状态沿用）
- 风控提示文案「止损按百分数（如 5 = 5%）；浮亏警戒为负数（如 -5）」保留为工具条下方小字
- 正文两列（信号区 | 持仓区）结构不变
- `board?.note` 提示、`boardError` 显示保留

## 不改动

- 后端 API、信号/持仓表结构、模式切换业务逻辑

## 验证

- `cd frontend && npm run build` 通过（vue-tsc + vite）
- `npm run lint:check`、`npm run format:check` 通过
