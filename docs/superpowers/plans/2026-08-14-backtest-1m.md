# 回测分钟线 1m Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 回测支持 `interval=1m`：加载分钟 K、vnpy `Interval.MINUTE`、现有 CTA 可跑，并限制交易日跨度。

**Architecture:** 泛化 `load_bars`；schema 增加 `max_trading_days`；`run_cta_backtest` 按 interval 映射；UI 周期选择 + Ops 引导。

**Tech Stack:** FastAPI、vnpy CTA、Vue 3、pytest

**Spec:** `docs/superpowers/specs/2026-08-14-backtest-1m-design.md`

## Global Constraints

- 只改 zak2；不 import zak / `vnpy_ashare`
- `interval` ∈ `{d, 1m}`；默认 `d`
- 1m：`max_trading_days` 默认 20，硬顶 60；按 distinct 日历日计数
- 1m 最低根数：`max(策略 min_bars, 100)`
- 1m 不足文案含 Ops / `fill_focus_pool_minute`
- 不新增分钟专用策略
- commit 简体中文；`./scripts/check.sh` 绿

### Task 1: Schema + 交易日/加载纯函数

**Files:**
- Modify: `backend/app/schemas/backtest.py`
- Modify: `backend/app/services/backtest_bars.py`
- Modify: `backend/app/services/backtest_settings.py`
- Test: `backend/tests/test_backtest_bars_interval.py`、扩展 `test_backtest_schemas.py`

**Interfaces:**
- `ALLOWED_INTERVALS = frozenset({"d", "1m"})`
- 请求：`interval` pattern / Literal；`max_trading_days: int = Field(20, ge=1, le=60)`
- `count_trading_days(bars: list[Bar]) -> int`
- `load_bars(db, *, vt_symbol, start_date, end_date, interval, min_bars, max_trading_days=None)`  
  - `interval=d`：行为同现 `load_daily_bars`（可让 `load_daily_bars` 调 `load_bars`）  
  - `interval=1m`：查 `interval=="1m"`；不足 → 404「分钟 K 不足…请先在 Ops 跑 fill_focus_pool_minute」；交易日 `> max_trading_days` → 400  
- `min_bars_for_request(req)`：若 `req.interval=="1m"` → `max(原值, 100)`

- [ ] **Step 2: schema 默认值测试**
- [ ] **Step 3: 实现 → 绿 → Commit**

