# ARQ 二期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ops 稳定 `_job_id` 去重 + worker bars 互斥；screener/backtest 迁 ARQ；删除内存 JobStore。

**Architecture:** 同队列 `zak2:arq`；统一旁路 `zak2:arq:jobs:*`；Ops 用 `_job_id=ops:{id}`（complete 后清 result 再入队）；bars 抢 `zak2:arq:lock:bars`；选股/回测随机 id。

**Tech Stack:** FastAPI、ARQ、Redis、pytest

**Spec:** `docs/superpowers/specs/2026-08-14-arq-phase2-design.md`

## Global Constraints

- 只改 zak2；不改 zak / vnpy-*
- Ops 撞车：`200` + 已有 `job_id`（稳定 id `ops:{ops_job_id}`）
- 去重范围：每个 Ops job 各自去重；bars 三组 worker 互斥
- screener/backtest **不**用稳定 `_job_id`；`result_ref` 仍为 run id
- 删除内存 JobStore；`/jobs` 只读旁路+ARQ
- commit message 简体中文：`<type>(<scope>): <简述>`
- `./scripts/check.sh` 最终必须绿

```python
# 从队列 ZSET 移除 stable_id（queue_name）
```
